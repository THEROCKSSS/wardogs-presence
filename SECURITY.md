# Security

Please report a suspected vulnerability privately through GitHub's **Report a vulnerability** feature on this repository. Do not include live webhook URLs in public issues. You can revoke a leaked webhook in Discord's channel Integrations settings.

WARDOGS Presence reads screen regions locally and sends status text to configured Discord webhooks. Optional server directory enrichment is disabled by default. Settings are stored in the current Windows user's AppData folder. The project does not provide a cloud account or remote control endpoint.
