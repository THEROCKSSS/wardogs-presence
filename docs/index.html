THE SETUP

Four steps to go live.

01 / DOWNLOAD

Run the single EXE

Download the portable Windows EXE from Releases and double-click it. The interface, Python engine, and OCR data are bundled. No installer or local server is needed.

02 / DISCORD

Connect your channels

In a Discord channel, open Edit Channel → Integrations → Webhooks → New Webhook. Copy its URL. In the app, enter your name and add the webhook under Discord channels. Enable one or several.

03 / CALIBRATE

Show it where to read

Open War Dogs in a match, show the pause menu, then use Screen capture → Capture in 5 sec. Drag the server, faction, and score reading boxes. Run OCR check and adjust until the readback is right.

04 / PLAY

Start the watcher

Save changes and select Start watcher. Status changes update an existing Discord message for each active destination. Close the window or stop the watcher to pause.

FIELD NOTES

When the signal is off.

Nothing appears in Discord

Check the watcher is running and the game is open. Test each enabled webhook. Save settings after editing. Webhook tests validate access without posting a message.

Wrong server or scores

Take another capture on the right monitor. Move the reading boxes around visible text and use OCR check to inspect what the engine sees.

Faction missing

In game settings, set Interface → Faction to Always On. Then move the faction reading box over the visible icon.

Protect your webhook

A webhook URL can post to its channel. Keep it private and revoke it in Discord if leaked. Never attach your AppData config to a public issue.

The app stores screenshots and settings locally. Status text goes to the Discord webhooks you enabled. Optional server directory enrichment is off by default.
